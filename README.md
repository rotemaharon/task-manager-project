# 📝 Task Manager Application

A fully responsive, modern Task Management web application built as my end-of-module project. 
This project demonstrates proficiency in Front-End development, DOM manipulation, and asynchronous programming.

## 🚀 Features
* **Create Tasks:** Add new tasks with descriptions and optional due dates.
* **Task Status:** Mark tasks as completed or active.
* **Filter Options:** Seamlessly switch between viewing All, Active, or Completed tasks.
* **Sort Functionality:** Sort tasks chronologically by their due date.
* **Data Persistence:** Utilizes the `localStorage` API to save tasks, ensuring data remains after page reloads.
* **External API Integration:** Automatically fetches initial dummy tasks from an external API (`JSONPlaceholder`) on the first load.
* **XSS Protection:** Implemented HTML escaping to sanitize user inputs and prevent Cross-Site Scripting vulnerabilities.

## 💻 Tech Stack
* **HTML5:** Semantic markup and structure.
* **CSS3:** Custom styling using CSS Variables, Flexbox, hover transitions, and fully responsive media queries.
* **JavaScript (ES6+):** Modular logic, DOM manipulation, Event Delegation, array methods (`map`, `filter`, `sort`), and asynchronous `fetch` requests.
