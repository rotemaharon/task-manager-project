# Task Manager Application
https://task-manager-project-ecru.vercel.app/

A responsive web application built for managing daily tasks. This project demonstrates core competencies in front-end development, DOM manipulation, asynchronous data fetching, and local data persistence.

## Features

* Task Creation: Add tasks with a description and an optional due date.
* Status Tracking: Mark tasks as completed or keep them active.
* Task Filtering: Filter the display to show all tasks, only active tasks, or only completed tasks.
* Chronological Sorting: Sort tasks by their specified due date.
* Data Persistence: Uses the localStorage API to retain task data across page refreshes.
* API Integration: Fetches initial sample data from an external API (JSONPlaceholder) when no local data is present.
* Security Implementation: Includes input sanitization to protect against Cross-Site Scripting (XSS) vulnerabilities.

## Tech Stack

* HTML5: Semantic structural markup.
* CSS3: Modern layouts using Flexbox, CSS variables, transitions, and media queries for mobile responsiveness.
* JavaScript (ES6+): Asynchronous operations, array methods (map, filter, sort), and event handling.
